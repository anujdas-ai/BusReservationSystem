# Bharat Yatra - Bus Reservation System

An Object-Oriented Java Desktop Application for intercity bus ticketing, live seat mapping, and depot management[cite: 2, 8].

## Download & Run
1. Download the latest **[BusReservationSystem.jar](https://github.com/Anjana-venugopal/BusReservationSystem/releases/latest)**.
2. Ensure you have [Java JDK/JRE 11+](https://www.oracle.com/java/technologies/downloads/) installed.
3. Double-click the `.jar` file to launch, or run in terminal:
   ```bash
   java -jar BusReservationSystem.jar
